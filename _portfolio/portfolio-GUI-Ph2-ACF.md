Created a GUI package for CMS Phase 2 Tracker module testing. It supports expert and non-expert testers by controlling testing workflows and providing database-based quality monitoring for the Phase 2 upgrade of the Compact Muon Solenoid Inner Tracker.

The main functionality includes:
* Test setup, control, and execution
* Visualization and quality assessment of test results
* Database communication for test and quality tracking
